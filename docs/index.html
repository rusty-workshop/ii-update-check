A pager for your dotfiles.

The illogical-impulse dots move fast. ii-update-check checks once a day and gives you a heads-up when there are new commits. It never pulls, never installs, never touches your system. It just beeps.

How it works.

One shell script and a systemd timer. That's the whole thing.

01 BASELINE

Remember where you are

The first run records the current upstream commit and stays quiet. No alert for history you've already seen.

02 COMPARE

Check once a day

Each run compares upstream main against the last-seen commit kept in ~/.cache.

03 BEEP

Tell you, then stop

If it moved, a desktop notification links straight to the commit log. What you do next is up to you.

Why it doesn't update for you.

The ii installer touches system packages and configs. That's not something to run unattended at 3am. So this tool's job ends at "hey, look".

✗ NEVER

  • runs the installer
  • pulls or merges anything
  • needs root
  • needs a GitHub account or token

✓ ALWAYS

  • tells you when upstream moved
  • links you to exactly what changed
  • lets you decide when to update
  • stays out of the way otherwise

Install.

git clone https://github.com/rusty-workshop/ii-update-check
cd ii-update-check
./check-ii-update.sh              # first run: records a baseline
mkdir -p ~/.config/systemd/user
cp systemd/ii-update-check.{service,timer} ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ii-update-check.timer
